## 接口信息（2026-11-22 已核对的公开文档）
- MiMo ASR：`POST https://api.xiaomimimo.com/v1/chat/completions`，模型 `mimo-v2.5-asr`，`api-key` 或 Bearer；WAV/MP3 走 `input_audio` data URI。
- MiMo LLM：`https://api.xiaomimimo.com/v1`，模型 `mimo-v2.6-flash` / `mimo-v2.6-pro`；thinking 模式下不要发送 temperature。
- Breeze TTS：`POST https://api.breeze.blue/v1/text-to-speech/{voice_id}`，`xi-api-key`，`model_id=breeze-tts-2`，`output_format=mp3_24000_128`。
- DeepSeek Flash：接口仍未提供。

## 仍缺
- MiMo API key（LLM 与 ASR 共用）。
- Breeze API key 与 voice_id（形如 `voc_...`）。
- 真实语音样本：优先放 WAV/MP3；MiMo 不接受 webm/ogg。
