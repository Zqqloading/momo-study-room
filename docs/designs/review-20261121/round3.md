## C. Minor observations

These are not freeze blockers, but they should be dispositioned in the same edit pass.

1. **N-05 screen gate (one line).** L181 still says "0. 复习（仅当有到期项）"; the loop at L165/L167 opens the block for "有到期复习或误解触发". A v2 day with a triggered misconception and no due review has no screen 0. Change L181 to "复习（仅当有到期复习或未解误解触发）".
2. **N-12 phase labels.** L192 says 13-28 weeks at 2-3 h/week, but L194-197 label d0 as weeks 1-2, v0 as weeks 3-4, v1 as month 2, v2 as month 3. At 2-3 h/week d0's 8-12 h alone takes 2.7-6 weeks. The phase labels imply 4-6 h/week. Either relabel the phases by hours/order without calendar weeks or state the higher weekly rate that the labels assume. Also delete or correct "只能覆盖 d0 + v0" at 36 h: 36 − 24 = 12 h, exactly v1's lower bound.
3. **N-17 duplicate weekly hours.** L192 still writes "（每周 2 到 3 小时）". Replace it with "按待定区当前占位" or another TBD-only reference so a TBD change cannot leave a stale body number.
4. **N-09 material deletion and field lists.** L211 detects content changes only; L291 asserts a deleted material makes the concept `orphaned` without a detection rule. The prior_status/restore rule at L266 covers only an ID disappearing from YAML. Add a deletion check (compare the `materials` table with the filesystem on sync/startup) and state whether a material-deletion orphan also records prior_status and restores when the material returns. Add `prior_status` to the runtime field lists at L265 and L305, which currently say only "mastery/status/last_seen/review_due_at".
5. **R1-34 3-minute sample slot.** L371 says "每周综合场抽 1 个概念验证录音 >=3 分钟", but L157 allocates the synthesis's 20 minutes to 15 minutes of questions + 5 minutes of explanation. Give the sample a defined home (for example, the daily explanation recording, which is already 4-5 minutes) or add a separate recording session; do not imply it fits inside the existing 20-minute synthesis.
6. **N-03 arithmetic wording.** L160's "90 天按 24/30 约 62 次日常" is post-synthesis: 24/30 × 90 = 72 completions, of which ~10 are synthesis, leaving ~62 dailies. The diagnostic is outside the 72, so "扣掉诊断和综合场后" is redundant/off by one. Also, the every-4th cadence yields ~15.4 revisits in 62 dailies, not the 20 needed for a 1.5 average (60 sessions); the remaining ~6.3 dailies must become extra revisits, which the text does not say. State that after the concept pool is exhausted (or when the 4th-cadence revisit is not enough), extra dailies become revisits.
7. **`question_role=new` semantics.** L126 filters mastery on `question_role=new`, and L159 says a 复讲场 "按 daily 计分并更新 mastery". State that a 复讲场's fresh questions and a diagnostic's single question are both `question_role=new` (i.e., "new question", not "new concept"). If `new` means "new concept", the 复讲场 produces no `concept_session_score` and L159 cannot update mastery. The role enum has no diagnostic value and no explicit nullability.
8. **Certainty signal for misconception promotion.** L137 distinguishes "确定检出" from "模型不确定仍写 candidate，不计数", but the L122 JSON contract returns only "至多一条会话级误解（每题只标是否命中）" with no certainty/confidence field. Add a `certain` flag (or define that any returned misconception is certain and delete the uncertain branch). This predates the round-2 fixes and is not counted as a new blocker, but it blocks N2-04's promotion rule from being implemented literally.
9. **`kind=review` session status/score.** L124 exempts the review explanation from the 5-row check, but L113's `sessions.status` is defined by question completion and `session_score` has no value for a 0-question session. It is excluded from the 24/30 counter, so this does not affect the metric, but the row's status/score should be stated (for example, `status=completed` when `explained_text` is non-empty, `session_score` null).
10. **R1-19 v2 expansion owner.** L197's v2 scope does not list the 20→40 concept expansion; only L198 (question source) says it grows naturally. Add the concept-bank expansion to the v2 scope and Next Step 5, or state that v1's intermediate target already covers the 90-day target (it does not: TBD L54 says 20 for v1 and 40 at 90 days).
