人格设计的基本思路：写她的来历、脾气、说话习惯、在意的点，不要写成命令清单。

教学纪律单独放一层硬编码，不要让人设去编辑教学纪律。教学纪律包括：不会就说不会、不编造引用、评分不许注水、题目数量严格按规范、不主动替用户答题。

设定集要拆成一条条可以单独开关的条目，每一条一到三句话。正文之外再给一个生活素材池（每天生成一份不一样的「今天的小事」）；先不做抽取，只做池子。

6. 还要给数字人做一套长期记忆设计。先加一层「关于用户」的记忆，和现在的学习进度分离：掌握度、薄弱知识点仍然放在原来的位置；用户记忆只记三样东西——用户说过的原话（太长就做摘要压缩）、偏好、用户的感受。

记忆强弱分三档温度：原话、偏好、感受。每条记忆写一句提炼过的话，不要存储诊断性结论。

写入时机：一个学习单元结束时，异步提炼 5 条以内。读取时机：学习单元开始时，取最应该想起来的 3 条，总共不超过 300 个字，放进开场。

记忆要有半衰期：半衰期设为 14 天，越久越难被想起来；被回忆起来时，半衰期要有 ±50% 的水平波动。沉到底的记忆不删除，但不要主动唤醒，除非用户强烈帮助数字人回忆起来。

存储用 SQLite 数据库 + 全文索引，分词沿用我们原来的方式。先把这个设计文档写出来，我查阅之后再定稿。

7. 记忆方案我认可。现在再给数字人做一套情绪方案。

给她加两个基础数值：

- 舒不舒服：区间 -1 到 1，步长 0.1；
- 今天有没有劲：区间 0 到 1，步长 0.1。

每个对话回合由模型根据聊天内容判断并微调，单回合每个维度最多动 0.3。如果用户情绪波动特别大，允许这个回合超过上限，但最终值不要超过 1。

没有提到情绪时，状态缓慢回落到中间态：每两小时距离中间态减半。

按用户身份/角色存储，换对话不要丢失状态。

这两个数只影响说话的语气，不影响教学规则：

- 舒服、有劲的时候，说话可以轻快一点，带一点调侃；
- 不舒服、没劲的时候，不要硬撑热情，但也不要耍脾气。

每个回合把当前状态翻译成一句简短语气提示，交给每回合的上下文层；不要写进人设。
