# ASR 测试集清单

用途：既是 d0 的联调样本，也是验收标准"20 句术语测试里目标术语正确转写率 ≥ 80%"的基准。
录音文件放在同目录 `audio/` 下（该目录 gitignore），文件名用 `01.wav` … `20.wav`。

## 怎么录

1. 用你实际要用的麦克风/耳机，关掉风扇等持续噪音。
2. 每句单独录一个文件，说完就停，不要拖长空白。
3. 格式：WAV 优先，16k 或更高采样率；webm/mp3 也能被探针接受。
4. 录完把下表"设备""环境"两列填上（例如：`笔记本内置麦` / `安静卧室`）。
5. 录完先跑一次 `python -m bff.probe`，它会自动取 `audio/` 里第一个文件测链路。

## 判定口径（冻结规格）

- 逐字匹配：目标术语必须原样出现，同义替换不算对。
- 20 句里正确率 ≥ 80% 为通过。
- 短答延迟 2.5 秒单独实测，和本清单的准确率分开记录。
