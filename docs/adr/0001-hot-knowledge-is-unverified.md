# 热知识是不进入主知识库的未核实层

会话中会出现材料之外的知识点。我们决定让它们以「热项」存在：可即时检索、带来源与 7 天有效期，但不写入概念出处、不作为计分题出处；只有经人工晋升、落成 `materials/inbox/` 文件并走完正常摄取与确认后，才进入主知识库。

**Considered Options**：直接把热项写进主知识库（快，但绕过原始快照的版本、切块与人工确认，会让同一场会话混用未核实与已核实内容）；只记日志不参与检索（安全，但"当天答不了"的问题没解决）。

**Consequences**：会话内可立即使用热点，但回答必须标注未核实；晋升多一步人工动作，热项在 7 天后过期。
