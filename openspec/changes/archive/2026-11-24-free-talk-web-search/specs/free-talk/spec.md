# Spec Delta

## ADDED Requirements

### Requirement: 联网兜底触发条件

自由对话 SHALL 先查本地材料。只有以下任一条件满足时才 MUST 调用联网搜索：用户显式要求（联网/查一下/最新）、问题命中时效关键词、本地检索未 grounded。MUST NOT 在本地已 grounded 且没有显式或时效信号时联网。

#### Scenario: 本地命中且无时效信号
- **WHEN** 本地检索有依据，问题不含时效词，用户也没说联网
- **THEN** 只依据本地材料回答，不调用搜索

#### Scenario: 用户显式要求联网
- **WHEN** 用户说「联网查一下 X」或「搜一下最新的 X」
- **THEN** 即使本地有命中，也调用联网搜索

#### Scenario: 问题具有时效性
- **WHEN** 问题包含「最新/今天/现在/新闻/价格/发布/版本/最近/谁/什么时候/今年」等词
- **THEN** 调用联网搜索

#### Scenario: 本地未命中
- **WHEN** 本地 `grounded=False`
- **THEN** 调用联网搜索

### Requirement: 材料优先与冲突并列

回答 SHALL 先依据本地材料。网页与材料冲突时 MUST 并列说明「材料说 X，网上有来源说 Y」，MUST NOT 用网页覆盖材料。

#### Scenario: 材料与网页冲突
- **WHEN** 材料说 A，网页来源说非 A
- **THEN** 回答同时说明两种说法，并标明材料优先

#### Scenario: 材料与网页一致
- **WHEN** 材料与网页说法一致
- **THEN** 回答统一表述，并同时列出材料与网页来源

### Requirement: 联网答案与引用

联网答案 MUST 为 1–3 句口语化文本。回答 MUST 附 1–3 条网页来源（标题、域名、日期、链接），并 MUST 明确「网上信息，可能变化」。网页来源 MUST 写入 `conversation_messages.sources_json`，刷新或切回旧对话后仍 MUST 可见。

#### Scenario: 正常联网回答
- **WHEN** 搜索返回可用结果
- **THEN** 回答简短口语化，附 1–3 条来源，并提示网上信息可能变化

#### Scenario: 刷新后回看
- **WHEN** 用户刷新页面并加载同一对话
- **THEN** 网页来源仍显示标题、域名、日期和链接

#### Scenario: 来源数量
- **WHEN** 可用结果超过 3 条
- **THEN** 最多展示 3 条网页来源

### Requirement: 搜索失败与空结果的兜底文案

搜索失败或超时时 MUST 回退本地结果；本地也未 grounded 时 MUST 明确说「材料里没有直接讲到，联网搜索暂时不可用」。搜索成功但没有可用结果时 MUST 说「材料里没有直接讲到，联网也没查到」。两种情况 MUST NOT 混用。

#### Scenario: 搜索失败
- **WHEN** 搜索报错或超时，本地也没有依据
- **THEN** 回答包含「联网搜索暂时不可用」

#### Scenario: 搜索空结果
- **WHEN** 搜索成功但没有可用结果，本地也没有依据
- **THEN** 回答包含「联网也没查到」

#### Scenario: 本地有依据但搜索失败
- **WHEN** 本地有依据，搜索失败
- **THEN** 回答只依据材料，不出现联网失败文案
